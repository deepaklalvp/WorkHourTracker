Common Issues

Quick solutions for frequently reported problems.

⚠️
⚠️ Terminal not found
This message typically occurs when the terminal you are trying to log in to is already active on a different device.

To deactivate:
  1. Open the LithosPOS application.
  2. Go to Menu → Settings → Account Details → Deactivate.
  3. If you cannot access the previous device, send a deactivation request from your registered LithosPOS email to support@lithospos.com.
🖼️ Images added in the back office not showing in POS
Start Menu → type Internet Options → Open Internet Options → Programs → Manage Add-ons → Learn more about toolbars and extensions → load the back office URL.
🖨️ KOT not generating
Ensure the kitchen printer is connected properly.
🐌 Slow system performance
Clear browser cache and restart the system.
🔄 Unable to sync data
Check server connectivity and retry sync.
