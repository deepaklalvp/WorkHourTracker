Quick solutions for frequently reported problems.

⚠️ Terminal not found
This message is regarding your query about the "Terminal Not Found" issue. Typically, this error occurs when the terminal you are trying to log in to is already active on a different device. To resolve this, you need to deactivate the terminal from the previous device before logging in to a new one.

To deactivate:
  1. Open the LithosPOS application.
  2. Go to Menu → Settings → Account Details → Deactivate .
  3. If you cannot access the previous device, please send a deactivation request from your registered LithosPOS email, mentioning your registered email ID and requesting deactivation, to support@lithospos.com.
Feel free to let us know if you need any more help.
🖼️ Images added in the back office not showing in the POS
Resolution:
  1. Open the Start Menu.
  2. Type Internet Options.
  3. Open Internet Options.
  4. Go to Programs.
  5. Open Manage Add-ons.
  6. Select Learn more about toolbars and extensions .
  7. In the new Internet Explorer window, load the back office URL.

⚖️ Weighing scale Connection
Step 1: First, you need to install Barcode Weighing Scale in the back office:

Back Office → Integrations

Step 2: In the back office, go to:

Settings → Barcode Scale → Enter Settings

By default:
  • Prefix: 9911
  • Entry code digit: 3
  • Weight digit: 5
  • Total: 12 digits
Step 3: After that, open an item and enable the weighing scale option.

When you enable the weighing scale, the barcode will automatically be generated according to the settings.

Step 4: Connect the weighing scale and print the barcode label with the weight.

Once you scan the barcode, the item and weight will be taken by the POS and the rate will be calculated accordingly.
⬜ White screen - Windows
Step 1: Press:

Windows Key + R

Step 2: In the popup, type:

%appdata%

Press Enter.

Step 3: In the new window, select the path and go to:

AppData → Local → Packages → Lithos Technosoft → LocalCache → Roaming → Lithos

Step 4: There will be a file named:

shared preferences

Rename the file.
🔄 Another sync in queue
"Currently another sync in Queue" means that a background sync is already going on. Usually, the sync will not take this much time.

Resolution:
  1. Ask the user to close the app completely from the background apps.
  2. Open the app again and try the sync.
  3. If the data is still not received, ask the user to change the internet connection.
  4. Share a hotspot from a personal phone and try again.
  5. Check the sync status again.
