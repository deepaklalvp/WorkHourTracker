⚠️ Terminal not found ⌄
This message is regarding your query about the "Terminal Not Found" issue. Typically, this error occurs when the terminal you are trying to log in to is already active on a different device. To resolve this, you need to deactivate the terminal from the previous device before logging in to a new one.

To deactivate:
  1. Open the LithosPOS application.
  2. Go to Menu → Settings → Account Details → Deactivate .
  3. If you cannot access the previous device, please send a deactivation request from your registered LithosPOS email, mentioning your registered email ID and requesting deactivation, to support@lithospos.com.
Feel free to let us know if you need any more help.
🖼️ Images added in the back office not showing in the POS ⌄
Resolution:
  1. Open the Start Menu.
  2. Type Internet Options.
  3. Open Internet Options.
  4. Go to Programs.
  5. Open Manage Add-ons.
  6. Select Learn more about toolbars and extensions .
  7. In the new Internet Explorer window, load the back office URL.

⚖️ Weighing scale Connection ⌄
Step 1: First, you need to install Barcode Weighing Scale in the back office:

Back Office → Integrations

Step 2:

In the back office, go to:

Settings → Barcode Scale → Enter Settings

By default:
  • Prefix: 9911
  • Entry code digit: 3
  • Weight digit: 5
  • Total: 12 digits
Step 3:

After that, open an item and enable the weighing scale option.

When you enable the weighing scale, the barcode will automatically be generated according to the settings.

Step 4:

Connect the weighing scale and print the barcode label with the weight.

Once you scan the barcode, the item and weight will be taken by the POS and the rate will be calculated accordingly.

🔄 Another sync in queue ⌄
"Currently another sync in Queue" means that a background sync is already going on.

Usually, the sync will not take this much time.

Resolution:
  1. Ask the user to close the app completely from the background apps.
  2. Open the app again and try the sync.
  3. If the data is still not received, ask the user to change the internet connection.
  4. Share a hotspot from a personal phone and try again.
  5. Check the sync status again.

📱 POS
Waiter App - how to connect
⌄
  1. In the LithosPOS application, go to Settings → KOT Server.
  2. Click Start Server and note the displayed IP Address and Port.
  3. Open the LithosPOS Waiter App.
  4. Enter the IP Address and Port and click Check Availability.
  5. If prompted, click Connect.
  6. Approve the connection request under KOT Server.
📚 View Waiter App Guide
🖨️ POS
How to add printer
⌄
  1. From the main menu, click Printers.
  2. Click the + button.
  3. Enter Printer Name, Printer Type and IP Address if required.
  4. Enable Receipt Print and KOT as required.
  5. For Bluetooth printers, pair the printer first from Device Settings.
  6. Click Test Print.
  7. Click Save.
🛒 Back Office
QK Order
⌄
Manage the QR code menu with Quiqqy Order:

1. Enable Quiqqy Order
  1. Go to Back Office → Settings → General → Features and enable Online Sale.
  2. Go to Integrations and enable Quiqqy Order.
2. Configure Quiqqy Order
  1. Go to Back Office → Online Order → Settings → Quiqqy .
  2. Fill in the store details and opening hours.
3. Generate and use Quiqqy Order links

https://quiqqy.com/storename/Table/table-number

Replace store-name with the configured store name.

Orders placed using these links will automatically be assigned to the specified table.
💳 On Account Sale
Setting up and using On Account
⌄
Install On Account feature
  1. Go to Back Office.
  2. Select Integrations.
  3. Install On Account.
Using On Account feature in POS
  1. Select the customer.
  2. Add the items and place the order.
  3. Go to Orders → Payment.
  4. Select On Account.
Check Customer Credit Balance on Back Office
  1. Go to Customers.
  2. Enable Balance from View.
  3. Search for the customer.
How to receive payment
  1. Go to Menu → Customers.
  2. Select the customer.
  3. Click Pay.
  4. Enter the amount and payment type.
  5. Click Submit.
👨‍🍳 Multi Kitchen
Setting up Multi Kitchen
⌄
Install Multi Kitchen feature
  1. Go to Back Office.
  2. Select Integrations.
  3. Install Multi Kitchen.
Enable Multi Kitchen for a store
  1. Go to Back Office → Store.
  2. Select the required store.
  3. Enable Multi Kitchen.
  4. Click Submit.
Adding Multi Kitchen
  1. Go to Kitchen Printers.
  2. Click Add Kitchen Printer.
  3. Select the categories for that kitchen.
  4. Click Submit.
KOT Printer Settings
  1. Go to POS Settings → Printers.
  2. Add the printer.
  3. Enable Print KOT.
  4. Select the required kitchens.
🧾 Add Tax
How to add tax
⌄
  1. Go to Back Office → Settings → General Settings .
  2. Select the Tax Type.
  3. Enable Include Tax if required.
  4. Submit the settings.
  5. Go to Settings → Taxes and add the required tax.
  6. Go to Settings → Store and enable tax for the store.
  7. Enter the TRN Number.
  8. Go to Back Office → Settings → Receipt and enable Tax Clarification.
  9. Add the tax to the required item.
